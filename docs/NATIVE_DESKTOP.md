# 原生桌面界面与输出说明

> 本文对应当前仓库源码；断点续算要求使用兼容的计算引擎版本。

2026-10-26：桌面入口改为 Qt Widgets，直接调用 `Simulation`；没有 WebView、网页嵌入或本地 HTTP 依赖。原有网页服务器作为单独的可选入口保留。

## 启动与语言

Windows 用户安装依赖后，使用根目录 `Start-GSRIM.cmd` 启动；`GSRIM-Desktop.cmd` 是同一入口的兼容别名。也可直接运行桌面模块：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe -m gsrim.desktop
```

右上角可选中文 / English。首次默认中文，此后记住语言选择。切换只更新标签、图表标题和提示，不重建计算任务，也不改写输入；尚未填完的输入也会保留。

## 控制面板

- **离子数据**：元素、原子序数、质量、能量、相对表面法线的入射角和计算类型。
- **靶材数据**：左侧添加、选择和删除层；右侧编辑所选层的元素。厚度支持 Å / nm / µm，配比按原子数输入。
- **化合物字典**：替换所选层的密度与成分，保留厚度。预设能量参数需要按实际材料核对。
- **特殊参数**：入射历史数、随机种子、批大小、截止能量、分箱、事件上限和物理模型。
- **输出文件**：选择导出项目；汇总、项目 JSON、结果 JSON 和 CSV 始终包含。
- **运行控制**：开始、暂停、继续、停止和恢复。底部也提供暂停、继续和停止，方便在结果页操作。

“参考工况：H → Ga₂O₃”依据用户提供的 `H/TDATA.txt` 输入 H 40 keV、6000 Å、5.88 g/cm³、O:Ga=3:2 以及对应结合能。这个按钮只载入参数，不运行 SRIM，也不把参考数据当作本程序计算结果。

添加或切换元素使用同一份逐元素建议表，覆盖 H～U；悬停能量单元格可查看建议来源。空白项表示已核对来源中缺少适用数值，需按材料填写，不能当作零。已有项目和显式化合物参数不会被新建议覆盖。详见[元素参数与来源](ELEMENT_DEFAULTS.md)。

## 图表与原始参考

结果页左侧选择分布、电子能量、晶格沉积、位移、转移能量、横向分布、能谱或入射轨迹。图表采用白底、红色填充、蓝色反冲曲线、灰色横向网格和科学计数法；深度默认以 Å 显示。分布图默认显示入射离子，可勾选“显示靶原子分布”加入逐元素曲线。可保存 1500×1050 PNG/BMP。

离子分布图在标题下以蓝色两列显示四项统计：左列“平均射程 / Ion Range”和“射程展宽 / Straggle”，右列“偏度 / Skewness”和“峰度 / Kurtosis”。前两项单位为 Å，后两项无量纲；保存的图片保留此栏。四项均来自停在靶内的入射离子原始终点，不包含背散射、透射或反冲原子，也不通过分箱曲线估算。展宽采用总体标准差，峰度采用正态分布为 3 的 Pearson 定义。部分运行显示当前已完成历史的统计；无可用数据或零展宽时，无法定义的量显示 N/A。

旧 JSON 缺失的偏度和峰度显示 N/A；载入保有原始终点的兼容 NPZ 时会重新计算。“载入参考文件夹”只读取参考文本实际报告的统计量，缺失项显示 N/A，不套用当前模拟的数值。`TDATA.txt`、`RANGE.txt` 和结果 JSON 同时保存新统计。

“载入参考文件夹”可读取 `RANGE.txt`、`IONIZ.txt`、`VACANCY.txt` 和存在时的 `PHONON.txt`。参考数据单独显示，不能导出为当前模拟或参与当前剂量换算。原始文件只读，参考中的空位含义与 GSRIM 的位移事件不合并。

当前模拟的“数据表”展示与图表一致的数值和单位。界面提示部分结果、旧版分项缺失及诊断结果。失败历史的科学文本导出和剂量换算保持禁用。

## 输出文件与物理量

导出会在所选位置新建唯一子文件夹，不覆盖之前导出。

| 文件 | 内容与单位 |
| --- | --- |
| `TDATA.txt` | 参数、各层成分、原子百分比、结合能、运行状态、来源和统计摘要 |
| `RANGE.txt` | 入射离子和各元素停止反冲分布，`(atoms/cm³)/(ions/cm²)` |
| `IONIZ.txt` | 离子 / 反冲的电子能量沉积，`eV/(Å·入射离子)` |
| `PHONON.txt` | 离子 / 反冲的晶格能量沉积，`eV/(Å·入射离子)` |
| `E2RECOIL.txt` | 离子 / 反冲引发的累计动能转移，`eV/(Å·入射离子)`；不是损伤能 |
| `DISPLACEMENTS.txt` | 初级反冲、各元素位移产生事件及总计，`events/(Å·入射离子)` |
| `VACANCY.txt`、`NOVAC.txt` | 说明稳定空位、替位未实现，无伪造数值表 |
| `LATERAL.txt` | 横向停止分布，`ions/(入射离子·分箱)` |
| `BACKSCAT.txt`、`TRANSMIT.txt`、`SPUTTER.txt` | 逃逸能谱，`particles/(入射离子·能量分箱)` |
| `ION_HISTORY.txt` | 可选逐历史状态、入射粒子终点、整条历史逃逸能量与失败标志 |
| `project.json`、`result.json`、`profiles.csv` | 参数、完整结果快照与原六通道统计 |
| `plot.png` | 当前选择的模拟图表 |

文件保留英文科学表头与列对齐、科学计数法结构，便于与参考文本对照；所有文件标明 GSRIM 身份、实际状态和来源，不声明与 SRIM 完全兼容或数值等价。

总量通道与 `detail_profiles` 分项分别提供整体计量、离子/反冲能量和逐元素停止、位移数据。

## 运行目录与断点

源码原生界面每次计算新建 `results/native/run-时间戳/`，包含 `project.json` 和 `autosave.npz`；若设置 `GSRIM_RESULTS_DIR`，则在该目录下新建运行目录。便携版在 EXE 旁的 results 中存储，不可写时回退到当前用户应用数据目录。

“恢复最近断点”读取原生界面上次运行路径；也可选择任意兼容 NPZ。暂停和退出会在当前批次结束并保存后生效。结果 JSON 是只读快照，不能恢复 GPU 计算。

Revision 4 不允许把 Revision 2 或更早历史混入续算；旧结果可作只读诊断查看，重新计算需重新开始。兼容断点缺少分项时 `detail_profiles` 为空。界面显示总量和“分项不可用”，不按比例虚构过去的离子/反冲分量；即使继续旧计算，也不把新累积的部分分项当作完整历史分项。
